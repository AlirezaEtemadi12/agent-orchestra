# Ideas

One file per idea that is **not yet a plan**. An idea is not a decision. When it is given a phase it
goes into the roadmap; when it is built it gets a plan, and its `Plan:` line points there. Add freely;
set `Status: dropped` (with one line why) rather than deleting, so the reason survives.

Header: `**Status:** raw · ready · planned · dropped` · `**Added:** <date>` · `**Plan:** <NNNN or —>`.
