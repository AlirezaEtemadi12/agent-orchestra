# Skill library

**Status:** raw · **Added:** 2026-11-19 · **Plan:** —

Keep the skills the owner has built in one place in Orchestra and attach them to a profile or a project, so every project can reuse them. Installing them in a project goes through a prompt the owner's agent runs (the dashboard never writes into a project — ADR 0005).

Open point: each agent has its own format (`SKILL.md` for Claude, rules for Cursor, …). Reuse across agents needs one agent-neutral source format and an export per agent.
