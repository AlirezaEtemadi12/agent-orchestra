# Start a session in Orchestra

Paste this as the first message of a new session opened **in this folder**
(`<orchestra>`):

```text
تو در پروژه‌ی Orchestra هستی: داشبورد و موتور مشترک ارکستر چندعاملی من.
قبل از هر کاری این‌ها را بخوان، به همین ترتیب:
1. AGENTS.md
2. .ai/README.md
3. جدیدترین .ai/context/session-*.md
4. .orchestra/workflow.md
5. .ai/vision/roadmap.md و .orchestra/ideas/README.md
6. .orchestra/plans/README.md

کار امروز: <کار امروز را اینجا بنویس>

قاعده‌ها:
- برای هر کار بزرگ‌تر از یک فایل: اول «فهم من از درخواست» را بنویس و صبر کن تا اصلاحش کنم،
  بعد پیش‌نمایش HTML را بساز، و بعد از تأیید من پلن را بنویس.
- طبق گیت‌های workflow.md کار کن. پلن، اجازه‌ی پیاده‌سازی نیست.
- تا نگفته‌ام «پیاده‌سازی کن»، هیچ کدی ننویس.
- به هیچ فایلی داخل Project A یا Project B دست نزن.
- اگر جایی درخواستم اشتباه یا مبهم بود، صریح بگو.
- آخر جلسه، session log را بنویس.
```
