# Session logs

One file per session: `session-YYYY-MM-DD-<gituser>.md` (add `-<topic>` when there are several that
day). Read the **newest** at session start.

A session log is a **log**: what changed, what was verified (real output), what is open. It is never
the home of a rule — a rule settled during the session is promoted into the `.ai/` doc that owns it
before the session ends, and the log links to it.

Sections: *Repository state* (branch, base, committed or not) · *What changed* · *Verified* ·
*Not verified* · *Open*.

Archiving follows Project B's policy (its `Agent/.ai/context/README.md` §Archiving): the last ten days
stay raw; older days are collapsed into `summaries/YYYY-MM.md`, one section per day.
